# AAC App Store Demo — Storyboard

**Target:** 30-second App Store preview video
**Format:** macOS screen recording, no narration, muted autoplay
**Structure:** 4 scenes stitched together

---

## Before you record

- Hide the Dock (System Settings → Dock → Automatically hide)
- Clean desktop — no files, no clutter
- Make the AAC window large (not full screen — show the macOS window frame)
- Use a real audiobook you've already converted (Star Trek series works well)
- Have Apple Books open and ready in the background

---

## Scene 1 — The Problem Setup (0–5 sec)

**What to show:** A Finder window full of MP3 files — many tracks, messy, no structure.

**Shot:**
- Open a Finder window showing a folder of MP3s (30+ files)
- Pause for 1–2 seconds so the viewer registers "this is a mess"

**Message conveyed:** *This is the raw material. It's chaos.*

**Tips:**
- Use a real multi-track audiobook folder
- Make the filenames visible (01-track.mp3, 02-track.mp3 etc.)

---

## Scene 2 — Import & Metadata (5–15 sec)

**What to show:** Drag the folder into AAC → tracks appear instantly → fill in metadata.

**Shots:**
1. Drag the Finder folder onto the AAC window (slow, deliberate drag)
2. Tracks populate the list — pause 1 second
3. Click into the Title field, type the book title (or show it already filled)
4. Click the artwork square — cover art appears

**Message conveyed:** *Seconds to import. Everything in one place.*

**Tips:**
- If metadata auto-fills from ID3 tags, even better — let the viewer see it happen
- Have the cover art image ready to click in quickly
- Don't rush the drag — slow is readable on a muted video

---

## Scene 3 — Export (15–22 sec)

**What to show:** Click Export → progress bar → M4B file lands in Finder.

**Shots:**
1. Click the Export button
2. Save panel appears — choose destination (Desktop or a clean folder)
3. Progress indicator runs (speed this up in iMovie if it's slow — trim to ~2 sec)
4. M4B file appears in Finder with the book's cover art as its icon

**Message conveyed:** *One click. Done.*

**Tips:**
- Export to a folder that's visible (Desktop works)
- After export, switch to Finder so the M4B file is clearly visible with artwork

---

## Scene 4 — Payoff in Apple Books (22–30 sec)

**What to show:** Open the M4B in Apple Books → chapter list visible → tap a chapter → it jumps.

**Shots:**
1. Double-click the M4B file — Apple Books opens it
2. Show the Now Playing screen with cover art, title, author
3. Tap the chapters button — chapter list appears (all named correctly)
4. Tap a chapter mid-book — playback jumps to that point
5. End on the chapter list or Now Playing — freeze frame

**Message conveyed:** *Real chapters. Real audiobook. It just works.*

**Tips:**
- This is the most important scene — spend the most time on it
- Make sure chapters are named (not just "Chapter 1, 2, 3" — real names if possible)
- The chapter jump is the wow moment — make it clearly visible

---

## Optional Scene — AAC+ (if time allows, replace Scene 1)

**What to show:** Drop an ePub → TTS converts → M4B with chapters.

**Shots:**
1. Click "Import ePub / PDF…"
2. Select an ePub file
3. Show the TTS progress (a few seconds)
4. M4B appears — open in Apple Books

**Use this if:** You want to highlight the ePub feature. Swap it for Scene 1 and tighten the other scenes.

---

## Editing notes for iMovie

- Each scene: trim aggressively — remove any hesitation or waiting
- Add a subtle fade between scenes (0.3s cross dissolve)
- Speed up any progress bars or loading to 2–4× (iMovie: clip speed)
- No music required for App Store (it plays muted) but a subtle track helps for the website version
- Export at 1920×1200 or 2560×1600 for App Store upload
